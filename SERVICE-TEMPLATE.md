# Service page template

Duplicate `service.html` for each service and update the marked **TEMPLATE** sections:

1. `<title>` and meta description
2. Breadcrumb + hero heading / lede
3. **What We Build** cards
4. **Development Process** steps
5. **Technologies** stack
6. **Service CTA** headline

Footer is loaded automatically from `partials/footer.html` via `script.js`.

Preview: `http://localhost:8766/service.html` (requires local server for footer import)
